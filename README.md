# Introduction to Neuroscience

Teaching materials and computational demonstrations for an introductory neuroscience course.

This repository contains short MATLAB simulations designed to help students connect neuroscientific concepts with simple computational models. Each activity is intended for exploration: run the example, change one parameter at a time, and compare the output with your predictions.

## Course materials

| Topic | Contents |
| --- | --- |
| [01 — Neural Plasticity](01-neural-plasticity/) | Hebbian learning; paired/unpaired activity; systematic parameter sweep |

Additional topics may be added during the course.

## Getting started

1. Open the topic folder above.
2. Read its `README.md` for instructions and questions.
3. Download a `.m` file (or the repository as a ZIP).
4. Open the script in MATLAB and select **Run**.

The current examples require MATLAB. The parameter-sweep script uses a local function at the end of the file and is intended for MATLAB R2016b or later. No additional toolboxes are required.

## How to use these simulations

The models are simplified teaching demonstrations, not quantitative reconstructions of biological experiments. Plot values and simulations should not be interpreted as empirical data. When working with a model, distinguish between its assumptions, its predictions, and the neuroscientific evidence.
